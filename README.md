# AuthSphere 🔐

### Secure User Authentication & Management REST API

AuthSphere is a backend REST API built with **Node.js, Express.js, and MongoDB**, focused on secure authentication, user management, and role-based authorization.

## 🚀 Features

* User Registration & Login
* Session-based Authentication
* Secure Logout
* User Profile Management
* Change Password
* Role-Based Authorization
* Admin User Management
* Password Hashing with bcrypt

## 🛠️ Tech Stack

* Node.js
* Express.js
* MongoDB
* Mongoose
* bcrypt
* express-session

## 📁 Structure

```text
src/
├── controllers/
├── middleware/
├── models/
└── routes/
```

## ⚙️ Setup

```bash
git clone <repository-url>
cd AuthSphere
npm install
npm run dev
```
